# 📱 SmartStore

SmartStore é um sistema web de catálogo de celulares, desenvolvido para funcionar como uma **vitrine digital moderna para lojas**.
Permite que clientes visualizem produtos, filtrem opções e acessem detalhes completos de forma simples e intuitiva.

---

## 🚀 Funcionalidades

* 📦 Listagem de produtos (iPhones do 11 ao 17)
* 🔍 Filtro por nome, marca e condição
* 📄 Paginação dos resultados
* 🪟 Modal com detalhes do produto
* 🖼️ Carrossel de imagens com:

  * Navegação por setas
  * Indicador de posição (bolinhas)
  * Zoom na imagem
* 💬 Botão de contato direto via WhatsApp

---

## 🛠️ Tecnologias

* HTML5
* CSS3
* JavaScript (Vanilla)

---

## 📌 Sobre o projeto

Este projeto foi desenvolvido como um **modelo base para sistemas de catálogo**, podendo ser facilmente adaptado para uso comercial, integração com APIs ou evolução para um sistema completo (SaaS).
